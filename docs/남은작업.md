## 1. 배포 전에 반드시 (환경 설정)

Vercel 환경변수에 아직 안 넣었다면 넣어야 동작하는 것들입니다.

| 변수 | 없으면 생기는 일 |
|---|---|
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` | **푸시 알림 전체 미동작** (특가·음용 적기) |
| `CRON_SECRET` | 정기 점검 API가 누구에게나 열림 |
| `DEEP_SEARCH=0` / `NEXT_PUBLIC_DEEP_SEARCH=0` | 웹 검색이 켜질 수 있음 → 스캔당 원가 7배 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 가격·이미지·시세 전부 미동작 |

- **MongoDB Atlas → Network Access** 에 `0.0.0.0/0` 이 열려 있어야 Vercel에서 접속됩니다.
- `vercel.json` 의 크론은 하루 한 번(`0 1 * * *`) 도는 것으로 설정되어 있습니다.

## 2. 아직 실기기에서 검증하지 못한 것

만들었지만 **실제로 돌려보지 않았습니다.** 시연 전에 한 번씩 확인이 필요합니다.

| 기능 | 확인 방법 | 위험 |
|---|---|---|
| **와인 리스트 스캔** | 실제 메뉴판 사진 한 장 | 판독 프롬프트 조정이 필요할 수 있음 |
| **공유 카드** | 결과 화면 → 이미지로 공유 | iOS 공유 시트 동작 확인 |
| **음용 적기 알림** | 크론 수동 실행 | 푸시 미설정이면 아예 안 감 |
| **특가 푸시** | 목표가를 현재가보다 높게 설정 후 크론 실행 | 위와 같음 |
| **셀러 가치** | 셀러 → [시세 갱신] | 항목이 많으면 60초 제한에 걸릴 수 있음 |
| **취향 추천** | 문답 8개 → 맞춤 탭 | 로컬에서는 정상 확인함 |

> **바코드**는 실기기에서 인식 확인을 마쳤습니다. 다만 대조표가 비어 있어 대부분 "등록되지 않음"이 나옵니다 (정상).

## 3. 데이터 — 가장 큰 남은 일

추천·검색의 품질은 결국 DB 크기에 달려 있습니다. **59종은 시연에는 되지만 서비스에는 부족합니다.**

### 3-1. 카탈로그 확장

채우는 길이 세 가지가 되었고, 전부 **AI 비용 0원**입니다.

| 방법 | 무엇이 들어오나 | 쓰는 법 |
|---|---|---|
| **네이버 인기 상품 수확** | 실제로 팔리는 술 (뼈대) | `POST /api/catalog/harvest` — 기본 dry-run, `confirm:true` 로 적재 |
| **미매칭 목록 보고 채우기** | 사용자가 찾았는데 없던 술 | `GET /api/wanted` 로 목록 확인 → 대화로 작성 |
| 대화로 직접 작성 | 산지·품종별 뼈대/전체 | `data/seed-*.json` → `POST /api/catalog/import` |

- Batch API(약 32원/종)는 **아직 실행하지 않았습니다.** 뼈대 구조가 생겨 급하지 않습니다 — 뼈대는 공짜고, 전체 분석은 사용자가 그 술을 찍는 순간 한 번만 일어납니다.
- 비어 있는 영역: 위스키(수확으로 일부 채워짐)·사케·전통주 전반, 편의점·마트 PB 와인.

### 3-2. 큐레이션 확장

`data/curation.json` 에 가격대·초보자 점수·태그를 매긴 것은 **와인 43종뿐**입니다.
그래서 입문자·가격대 추천은 와인으로 한정해 두었습니다. 위스키까지 넓히려면 위스키 큐레이션이 필요합니다.

### 3-3. 상품 이미지 12종 미확보

`POST /api/catalog/images` 로 채웁니다. 60초 제한이 있어 `limit` 을 10 안팎으로 나눠 돌려야 합니다.
표기 변형 재시도를 넣은 뒤로 적중률이 올라갔으니 다시 돌리면 더 채워질 수 있습니다.

## 4. 상업화에 필요한 것 (클라이언트 컨펌 후)

### 4-1. 로그인 · 만 19세 인증 · 사용량 제한 ★★★

**지금은 모든 기록이 기기 단위로 공용입니다.** 사용자 구분이 없습니다.

- 카카오·네이버 소셜 로그인
- 만 19세 이상 확인 — 청소년보호법상 필요하고 앱스토어 심사에서도 봅니다. 소셜 로그인 생년월일로 1차 확인 후 본인인증(PASS 등) 연동 권장
- 사용량 제한 — 무료 사용자의 스캔 횟수를 막지 않으면 AI 비용이 그대로 적자가 됩니다
- 미성년자 차단 문구·음주 경고 문구 노출

> 화면 레이아웃은 **[내 정보] 서랍에 이미 잡아 두었습니다.** 인증만 붙이면 그대로 살아납니다.

### 4-2. 데이터 이전 계획

지금 쌓이는 기록(셀러·노트·취향·평점)은 기기 단위입니다. 로그인을 붙일 때
**기존 기록을 계정으로 옮기는 절차**를 함께 만들어야 합니다. 지금 안 정해 두면 나중에 버리게 됩니다.

### 4-3. 수익 모델

- 구독제 (무료 월 N회 / 프리미엄 무제한)
- 구매 연결 제휴 수수료
- B2B — 보틀샵·마트 위젯, 주류 이커머스 대상 분석 API

## 6. 품질·정합성으로 남은 것

- **`lowestPrice` 판정 기준** — 중앙값 40% 미만 제외 + 4배 이상 흩어지면 표시 안 함. 보수적이라 기준가가 자주 숨습니다. 실사용 데이터를 보고 조정해야 합니다.
- **특가 판정 기간** — 화면은 "6개월 최저"로 보여주는데, 알림 판정은 `priceLow`(관찰 이래 전체)를 씁니다. 이력 보관이 190일이라 실질 차이는 작지만 기준이 다릅니다.
- **`/api/catalog/images` 60초 제한** — 한 번에 20종을 넘기면 중간에 끊깁니다.
- **큐레이션 가격대는 우리 추정치**입니다. 실제 시세와 어긋나면 `data/curation.json` 을 손봐야 합니다.
- **네이버 오픈 API 이용약관** — 출처 표기·이미지 사용 조건을 정식 오픈 전에 직접 확인해 주세요. 현재 구조는 위험을 줄인 것이지 법률 검토를 대신하지 않습니다.

## 7. 디자인으로 남은 것

- **가로형 워드마크** — 받은 워드마크는 두 줄로 쌓인 형태라 헤더에서 글자가 뭉개집니다. 지금은 심볼만 이미지로 쓰고 글자는 조판했습니다. 가로형(6:1)을 하나 더 받으면 헤더도 이미지로 통일할 수 있습니다.
- **PWA 아이콘** — 모노그램(`img_a.png`)이 1MB에 가깝습니다. 512×512로 줄인 파일을 `public/icons/icon.png` 에 넣으면 설치 아이콘이 깔끔해집니다.
- **빈 상태 일러스트** — 셀러·히스토리의 빈 화면이 아직 주종 아이콘을 재활용하고 있습니다.
