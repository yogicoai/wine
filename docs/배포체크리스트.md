# Vercel 배포 체크리스트

배포하면 **HTTPS가 자동으로 붙어 폰에서 카메라 촬영 시연이 가능해집니다.**
아래 ①②는 하지 않으면 배포해도 동작하지 않습니다.

---

## ① MongoDB 접속 허용 ⚠️ 필수

Vercel은 서버 IP가 매번 바뀌기 때문에, 지금 설정으로는 **DB 연결이 막힙니다.**

1. MongoDB Atlas 접속 → 좌측 **Network Access**
2. **ADD IP ADDRESS** → **ALLOW ACCESS FROM ANYWHERE** (`0.0.0.0/0`) 선택 → Confirm

> 보안이 걱정되시면, 정식 출시 때 Vercel의 고정 IP 기능이나 Atlas–Vercel 연동으로 좁히면 됩니다. 시연 단계에서는 이 방법이 표준입니다.

---

## ② Vercel 환경변수 입력 ⚠️ 필수

`.env.local`은 보안상 저장소에 올라가지 않으므로, **Vercel 대시보드에 직접 넣어야 합니다.**

프로젝트 → **Settings → Environment Variables** → 아래 값을 하나씩 추가 (Production·Preview 모두 체크)

| 이름 | 값 |
|---|---|
| `ANTHROPIC_API_KEY` | 로컬 `.env.local`과 동일 |
| `CLAUDE_MODEL` | `claude-sonnet-5` |
| `IDENTIFY_MODEL` | `claude-haiku-4-5` |
| `PRESCAN` | `1` |
| `WEB_SEARCH` | `0` |
| `DEEP_SEARCH` | `0` |
| `NEXT_PUBLIC_DEEP_SEARCH` | `0` |
| `MONGODB_URI` | 로컬과 동일 |
| `MONGODB_DB` | `winelens` |
| `NAVER_CLIENT_ID` | 로컬과 동일 |
| `NAVER_CLIENT_SECRET` | 로컬과 동일 |
| `YOGIBO_FTP` | `yogibo.ftp.cafe24.com` |
| `YOGIBO_FTP_ID` | 로컬과 동일 |
| `YOGIBO_FTP_PW` | 로컬과 동일 |
| `YOGIBO_FPT_LINK` | `/app/img/wine/` |
| `FTP_PUBLIC_BASE` | `https://yogibo.openhost.cafe24.com/` |
| `VAPID_PUBLIC_KEY` | 로컬과 동일 (특가 알림용) |
| `VAPID_PRIVATE_KEY` | 로컬과 동일 |
| `VAPID_SUBJECT` | `mailto:yogico.ai@gmail.com` |
| `CRON_SECRET` | 로컬과 동일 (정기 점검 보호용) |

> 💡 로컬 `.env.local` 내용을 그대로 복사해 Vercel의 붙여넣기 입력창에 한 번에 넣을 수도 있습니다.

## ③ GitHub 저장소 올리기

이 폴더를 독립 저장소로 초기화해 두었습니다. 이제 GitHub에 올리면 됩니다.

```bash
# 1. GitHub에서 빈 저장소 생성 (예: bottle-lens) — README 체크 해제
# 2. 아래 명령 실행
git commit -m "보틀 렌즈 초기 버전"
git branch -M main
git remote add origin https://github.com/<계정>/bottle-lens.git
git push -u origin main
```

그다음 Vercel에서 **Add New → Project → 해당 저장소 Import** → 환경변수 입력 → Deploy.

프레임워크는 Next.js로 자동 인식되며, 빌드 설정은 손대지 않아도 됩니다.

## ④ 특가 알림 (자동 설정됨)

배포하면 **매일 새벽 1시에 셀러·위시리스트의 가격을 자동으로 점검**하고, 특가가 있으면 휴대폰으로 알림을 보냅니다. `vercel.json`에 일정이 들어 있어 별도 설정은 필요 없습니다.

사용자는 **셀러 화면의 "특가 알림 → 켜기"** 버튼으로 구독합니다.

| 항목 | 내용 |
|---|---|
| 점검 주기 | 하루 1회 (무료 플랜 한도) |
| 알림 조건 | 목표가 도달 · 역대 최저가 대비 5% 이상 하락 |
| 중복 방지 | 같은 술을 같은 가격으로 다시 알리지 않음 |
| iPhone | **홈 화면에 추가한 뒤**에만 알림이 옵니다 (iOS 정책) |
| Android · PC | 브라우저에서 바로 가능 |

## ⑤ 배포 후 확인 순서

폰에서 배포 주소를 열고 아래를 차례로 확인하세요.

1. **카메라가 열리는가** — 권한 허용 팝업 → 화면에 카메라 화면이 보이면 성공
2. **술병 스캔** — 실제 병을 찍어 결과가 나오는지 (약 30초)
3. **구매 정보 카드** — 상품 사진과 가격이 뜨는지
4. **셀러 담기 → 테이스팅 노트** — DB 저장이 되는지
5. **홈 화면에 추가** — 브라우저 메뉴에서 추가하면 앱처럼 전체화면으로 실행됩니다 (시연용으로 좋습니다)
6. **설명서** — `배포주소/guide`

## 알아두실 제약

| 항목 | 내용 |
|---|---|
| **웹 검색 분석** | 스캔당 316원·3분이 들고 무료 플랜(60초)에서는 타임아웃되므로 **꺼 두었습니다**(`DEEP_SEARCH=0`). 화면에도 나오지 않고 서버에서도 차단됩니다. Vercel Pro로 올린 뒤 쓰시려면 `DEEP_SEARCH=1`, `NEXT_PUBLIC_DEEP_SEARCH=1` 로 바꾸면 됩니다. |
| **이미지 업로드** | 서버리스 환경에서 FTP가 막힐 수 있습니다. 실패해도 자동으로 기존 방식(DB 저장)으로 넘어가므로 **기능이 멈추지는 않습니다.** 배포 후 이미지가 잘 뜨는지만 확인해 주세요. |
| **첫 접속 지연** | 한동안 사용이 없으면 첫 요청이 몇 초 느릴 수 있습니다(콜드 스타트). 시연 직전에 한 번 열어두면 됩니다. |
| **검색 노출** | 시연 단계라 검색엔진에 잡히지 않도록 막아 두었습니다. 정식 출시 때 풀면 됩니다. |

## 이미 처리해 둔 것

- 서버리스 실행 시간 제한(60초)에 맞춰 조정
- 모바일 화면 설정(viewport)·상단바 색상·노치 대응
- 홈 화면 설치용 앱 아이콘과 매니페스트
- 이모지 대신 SVG 아이콘 (기기마다 깨지던 문제 해결)
- 환경변수 파일이 저장소에 올라가지 않도록 차단
- FTP 실패 시 자동 폴백 (기능 중단 없음)
